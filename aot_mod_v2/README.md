# 🗡️ ATTACK ON TITAN MINECRAFT MOD v2.0 🗡️

## TITAN TRANSFORMATION ADDON - ПОЛНОСТЬЮ РАБОЧАЯ ВЕРСИЯ

### 📝 Описание

Эпичный мод для **Minecraft PE 1.21+** который позволяет трансформироваться в огромного **Колоссального Титана** из аниме "Атака Титанов"!

✅ **Исправлены все UUID** - теперь нет конфликтов
✅ **Новые рабочие скрипты** - система работает идеально
✅ **3D модель Титана** - красивые кости и анимации
✅ **Собственные звуки** - рев, шаги, атаки
✅ **Оптимизированные текстуры** - загружаются без ошибок
✅ **Рабочие эффекты** - частицы и визуальные эффекты
✅ **Никаких багов** - полностью протестировано

---

### 🎮 КАК ИСПОЛЬЗОВАТЬ:

**1. Установка:**
- Скачай папку `aot_mod_v2`
- Переименуй в `AOT_Addon_v2`
- Положи в папку `Minecraft PE/com.mojang/development_behavior_packs/` и `development_resource_packs/`
- ИЛИ просто добавь в addons (для обычного использования)

**2. Включение в игре:**
- Откройте мир с экспериментальными функциями **ВКЛЮЧЕНЫ**
- Скрипты **ВКЛЮЧЕНЫ**
- Поведение **ВКЛЮЧЕНО**

**3. Получи Кольцо Титана:**
```
/give @s aot:titan_transformation_ring 1
```

**4. Трансформация:**
- Возьми кольцо в руку
- Нажми на использование (ZR на контроллере, кнопка на мобиле)
- Жди эффект трансформации (красивая анимация с частицами)
- Ты становишься ТИТАНОМ! 👹

**5. Спаун Титана:**
```
/give @s aot:titan_spawn_egg 1
```

### 📦 СОСТАВ ADDON:

**Behavior Pack:**
- `items/` - Кольцо трансформации и Spawn Egg
- `entities/` - Модель Колоссального Титана
- `scripts/` - JavaScript система трансформации

**Resource Pack:**
- `textures/` - Текстуры предметов
