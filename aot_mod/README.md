# 🗡️ ATTACK ON TITAN MINECRAFT MOD 🗡️

## Трансформация в Атакующего Титана!

### Описание
Эпичный мод для Minecraft PE 1.21+ который позволяет трансформироваться в огромного **Атакующего Титана** из аниме "Атака Титанов"!

### 🎮 Как использовать

1. **Установи мод** в папку addons
2. **Создай Титаново Кольцо** командой:
   ```
   /give @s aot:titan_ring 1
   ```
3. **Экипируй кольцо** как обычный предмет
4. **Нажми использовать** (зажми LT/L2)
5. **Трансформируйся в Титана!**

### ⚡ Возможности

- ✨ **Эпичная трансформация** с эффектами и звуками
- 👹 **4.5x больший размер** (как Атакующий Титан)
- 💪 **Увеличенная сила и скорость**
- 🔥 **500 HP** - очень крепкий
- 🎬 **Крутые анимации атаки**
- 🔊 **Оригинальные звуки рева титана**
- ⏱️ **15 секунд боевой формы**

### 📋 Фишки

- Титан может атаковать врагов мощными ударами (25 урона)
- При трансформации получаешь эффекты силы и скорости
- Кольцо невозможно выбросить - только на тебе
- Красивые эффекты при появлении
- Крутой рев при атаке

### 🎵 Звуки
- Рев Титана при трансформации
- Звуки боли Титана
- Звуки шагов
- Эпичная музыка

### 📦 Состав мода

- **Behavior Pack** - все механики и функции
- **Resource Pack** - текстуры, звуки, модели
- **JavaScript скрипты** - система трансформации

### ⚙️ Требования

- Minecraft PE 1.21.0+
- Экспериментальные функции: ВКЛ
- Скрипты: ВКЛЮЧЕНЫ

### 🎯 Команды

```
/give @s aot:titan_ring 1  - Получить кольцо
/summon aot:attacking_titan  - Спаун Титана
```
