## 🎯 AIM BOT

### Описание
Автоматическая система наведения на врагов с предсказанием их движения.

### Параметры

#### FOV (Field of View)
- **Диапазон:** 50-500 пиксели
- **Описание:** Радиус области вокруг центра экрана, в которой система ищет врагов
- **Рекомендация:** 200-300 для оптимальной игры

#### Smoothness (Плавность)
- **Диапазон:** 0.1-1.0
- **Описание:** Скорость поворота камеры к цели
  - 0.1 = очень медленно (неестественно)
  - 0.5 = нормально
  - 1.0 = мгновенно (подозрительно)
- **Рекомендация:** 0.3-0.5

#### Prediction (Предсказание)
- **Описание:** Предсказывает будущее положение врага на основе его скорости
- **Преимущество:** Повышает точность стрельбы по движущимся целям
- **Рекомендация:** Включить для лучшей точности

### Как работает
1. Система сканирует всех врагов в радиусе FOV
2. Находит ближайшего врага
3. Если Prediction включена - предсказывает его позицию
4. Плавно наводит камеру на цель

### Горячая клавиша
**Q** - Быстро вкл/выкл Aim Bot

## 🔫 SHOOTER

### Описание
Функции для улучшения стрельбы и отладки механики выстрелов.

### Параметры

#### Auto Shoot (Автоматическая стрельба)
- **Описание:** Автоматически стреляет, когда цель в центре экрана
- **Использование:** Используется вместе с Aim Bot
- **Горячая клавиша:** E

#### No Recoil (Отсутствие отдачи)
- **Описание:** Убирает отдачу оружия при выстреле
- **Эффект:** Пули летят прямо без разброса
- **Горячая клавиша:** F

#### Infinite Ammo (Бесконечные патроны)
- **Описание:** Отключает трату патронов
- **Эффект:** Можно стрелять бесконечно
- **Горячая клавиша:** C

#### Bullet Speed (Скорость пуль)
- **Диапазон:** 50-200 единиц/сек
- **Описание:** Увеличивает скорость полета пуль
- **Преимущество:** Сложнее избежать
- **Рекомендация:** 100-120

#### Shoot Delay (Задержка между выстрелами)
- **Диапазон:** 50-500 миллисекунд
- **Описание:** Минимальное время между выстрелами
- **Преимущество:** Больше урона в секунду
- **Рекомендация:** 100-150мс

### Комбинация для Максимума
```
1. Включить Aim Bot (Q)
2. Включить Auto Shoot (E)
3. Включить No Recoil (F)
4. Настроить Shoot Delay на 100мс
5. Увеличить Bullet Speed на 120
```

## 👁️ ESP (Electronic Surveillance Package)

### Описание
Визуальная система для видения врагов через стены и препятствия.

### Параметры

#### ESP (Основной toggle)
- **Описание:** Включает/выключает всю ESP систему
- **Горячая клавиша:** X

#### Show Distance (Показывать расстояние)
- **Описание:** Отображает расстояние до врага в метрах
- **Формат:** `Имя игрока\nХХ м`

#### Show HP (Показывать здоровье)
- **Описание:** Отображает текущее здоровье врага
- **Формат:** `Имя игрока\nHP: XX`

#### Max Distance (Максимальная дистанция)
- **Диапазон:** 50-1000 стадов (1 стад ≈ 28см)
- **Описание:** На какой дальности видна ESP
- **Рекомендация:** 500 (примерно 140 метров)

### Визуальная информация
ЭПС показывает над каждым врагом:
- 🔴 **Красный текст** - враги
- 🟢 **Зелёный текст** - (может быть для команды)
- **Расстояние** - расстояние в метрах
- **HP** - текущее здоровье

## 🎨 GUI MENU

### Описание
Красивое и функциональное меню для управления всеми функциями.

### Элементы меню

#### Заголовок
- **Текст:** 🎯 RIVALS MOD
- **Цвет:** Фиолетовый
- **Размер:** 400x60 пиксели

#### Центральный круг (Прицел)
- **Размер:** 60x60 пиксели
- **Цвет:** Циан (синий)
- **Положение:** Центр экрана
- **Эффект:** Меняет цвет на красный при активной цели

#### Тоглы
- **ON** - зелёный (включено)
- **OFF** - красный (выключено)
- **Клик** - переключает состояние

#### Слайдеры
- **Минимум-Максимум** - диапазон значений
- **Перетаскивание** - Выбор значения
- **Отображение** - Текущее значение

#### Закрытие меню
- **Кнопка:** ✕ (крестик в углу)
- **Эффект:** Плавное закрытие с анимацией

### Дизайн
- **Основной цвет:** Фиолетовый (#8A2BE2)
- **Вторичный цвет:** Розовый (#FF1493)
- **Акцент:** Циан (#00FFFF)
- **Фон:** Тёмный (#141E1E)
- **Граница:** 3px фиолетовая
- **Углы:** Закруглённые (15px radius)

## ⌨️ ГОРЯЧИЕ КЛАВИШИ

### Меню
```
INSERT или DEL - Открыть/Закрыть меню
```

### Быстрые Тоглы
```
Q - Aim Bot вкл/выкл
E - Auto Shoot вкл/выкл
F - No Recoil вкл/выкл
X - ESP вкл/выкл
C - Infinite Ammo вкл/выкл
TAB - Переключить цель (если Aim Bot активен)
```

### Комбинации
```
Q + E - Aim Bot + Auto Shoot (автоуничтожение)
E + F - Auto Shoot + No Recoil (высокая точность)
X + Q - ESP + Aim Bot (полный контроль ситуации)
```

## 💡 СОВЕТЫ И ТРЮКИ

1. **Естественность:** Увеличьте Smoothness, чтобы не выглядеть подозрительно
2. **Точность:** Включите Prediction для лучшей точности
3. **Скорость:** Уменьшите Shoot Delay для большего урона/сек
4. **Зрение:** Увеличьте ESP Distance для лучшей осведомленности
5. **Баланс:** Не включайте всё одновременно - выглядит подозрительно!
