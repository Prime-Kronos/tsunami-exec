# 🎯 RIVALS GUI SCRIPT - SHOOTER MOD 🎯

## Красивое Меню с Функционалом для Стрелялки

### 📝 Описание
Профессиональный Lua скрипт для Roblox игры "Rivals" с красивым GUI меню и полным функционалом для стрелялки.

### ✨ ВОЗМОЖНОСТИ:

✅ **Красивое GUI Меню**
- Плавная анимация окна
- Круг визуализации в центре экрана
- Красивые кнопки и тоглы
- Фиолетовая и неоновая цветовая схема

✅ **Функции Aim Bot:**
- Автоматический прицел на врагов
- Предсказание движения
- Смена целей (Tab)
- Настройка дальности прицеливания

✅ **Shooter Функции:**
- Автоматическая стрельба
- No Recoil (отсутствие отдачи)
- Увеличенная скорость пуль
- Бесконечные патроны

✅ **ESP:**
- Видимость врагов через стены
- Отображение дистанции
- Отображение HP
- Разные цвета для своих и врагов

✅ **Настройки:**
- FOV для прицела
- Чувствительность
- Скорость пуль
- Сохранение настроек

### 🎮 КАК ИСПОЛЬЗОВАТЬ:

1. **Вставь скрипт** в StarterPlayer > StarterCharacterScripts или StarterPlayer > StarterPlayerScripts
2. **Запусти игру**
3. **Нажми `INSERT` или `DEL`** - откроется меню
4. **Включи нужные функции** - тоглы сверху
5. **Настрой параметры** - слайдеры внизу
6. **Наслаждайся игрой!** 🎯

### ⌨️ ГОРЯЧИЕ КЛАВИШИ:

```
INSERT / DEL      - Открыть/Закрыть меню
TAB              - Переключить цель Aim Bot
Q                - Вкл/Выкл Aim Bot
E                - Вкл/Выкл Auto Shoot
F                - Вкл/Выкл No Recoil
X                - Вкл/Выкл ESP
C                - Вкл/Выкл Infinite Ammo
```
