# 📥 РУКОВОДСТВО ПО УСТАНОВКЕ - RIVALS GUI SCRIPT

## Способ 1: Roblox Studio (Рекомендуется для разработки)

### Шаги:

1. **Откройте Roblox Studio**
   - Запустите Roblox Studio
   - Создайте новый проект или откройте существующий

2. **Добавьте скрипт в иерархию:**
   - Клик правой кнопкой на `StarterPlayer` в левой панели
   - Выберите `Insert Object` → `LocalScript`
   - Переименуйте в `RivalsModScript`

3. **Вставьте код:**
   - Откройте файл `main.lua`
   - Скопируйте весь код
   - Вставьте его в скрипт в Studio

4. **Запустите:**
   - Нажмите кнопку `Play` в Studio
   - Скрипт будет загружен автоматически

---

## Способ 2: Roblox Game (Использование в сервере)

### Для владельца сервера:

1. **Добавьте скрипт на сервер:**
   - В `ServerScriptService` добавьте новый `Script`
   - Вставьте модифицированный код для серверной части

2. **Загружайте с клиента:**
   - Пользователи с модом смогут загружать `main.lua` через консоль

### Для игроков (используя консоль):

1. **Откройте консоль разработчика:**
   - Нажмите `F12` в браузере (Chrome/Firefox)
   - Или `Ctrl + Shift + J` на Windows

2. **Перейдите на вкладку `Console`**

3. **Вставьте код загрузчика:**
```lua
local script = Instance.new("LocalScript")
script.Source = [[ -- ВСТАВЬТЕ КОД main.lua ЗДЕСЬ ]]
script.Parent = game.Players.LocalPlayer:WaitForChild("PlayerGui")
```

4. **Нажмите Enter**

## Способ 3: Использование в ReShade / Overlay Scripts

### Если вы используете скрипт-инжектор:

1. **Скопируйте файл `main.lua`** в папку скриптов инжектора

2. **В файле конфигурации инжектора** добавьте:
```lua
local script = require("main.lua")
script.init()
```

3. **Перезагрузите инжектор**

## 🐛 РЕШЕНИЕ ПРОБЛЕМ:

### Проблема: Скрипт не загружается
**Решение:**
- Проверьте, что вы в `LocalScript`, а не в обычном `Script`
- Убедитесь, что скрипт находится в нужном месте
- Перезагрузите игру

### Проблема: Меню не открывается
**Решение:**
- Проверьте горячие клавиши (INSERT/DEL)
- Убедитесь, что GUI включена в настройках
- Попробуйте `F12` для консоли браузера

### Проблема: Aim Bot не работает
**Решение:**
- Включите Aim Bot кнопкой Q
- Проверьте FOV в меню (минимум 50)
- Убедитесь, что враги видны в FOV
